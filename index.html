Formulare automatisch auslesen

  1. console.anthropic.com öffnen und anmelden.
  2. Unter Billing einmalig Guthaben aufladen – 5 € reichen für mehrere tausend Formulare.
  3. Unter API Keys auf Create Key, den Schlüssel kopieren.
  4. Hier unten einfügen und speichern. Fertig.

Ohne Schlüssel funktioniert das Scannen weiterhin – die Felder werden dann von Hand eingetippt, während das Foto danebensteht.

Der Schlüssel liegt nur in diesem Browser, nicht in der Programmdatei. Wenn du die Datei weitergibst, geht er nicht mit. Pro Formular fallen Bruchteile eines Cents an.

Nur ändern, wenn es einen Grund gibt. „claude-sonnet-5-5“ liest Handschrift am zuverlässigsten.
